Check the record yourself

Each forecast is one line of data/ledger.jsonl. Every line carries the fingerprint of the line before it, so editing or deleting an old forecast breaks the chain.

The git history of that file shows when each forecast was committed, by GitHub's clock and not Oracle's.

git clone https://github.com/mahir-patel/Oracle.git
cd Oracle
pip install .
oracle verify

The last command recomputes the whole chain and reports whether it is intact.
